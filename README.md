# sort_report
排序演算法分析報告一、 前言排序演算法是計算機科學中最基礎且重要的核心技術之一。不同的演算法在時間效率、空間耗用上各有優劣。本報告旨在探討五種經典的排序演算法：氣泡排序（Bubble Sort）、選擇排序（Selection Sort）、插入排序（Insertion Sort）、合併排序（Merge Sort）與堆積排序（Heap Sort），透過理論探討與實際的數據模擬，比較它們在不同資料規模（n）下的效能表現與特性差異。二、 排序法原理1. 氣泡排序法 (Bubble Sort)基本原理：透過重複走訪要排序的數列，一次比較兩個相鄰的元素。如果它們的順序錯誤就把他們交換過來。操作方式：每一輪走訪都會把未排序區段中的最大（或最小）值，像氣泡一樣「浮」到數列的頂端。持續進行直到沒有需要交換的元素為止。2. 選擇排序法 (Selection Sort)基本原理：將資料分為「已排序」與「未排序」兩個區段。操作方式：每一輪從「未排序」的區段中尋找最小值，找到後將它與未排序區段的「第一個元素」進行交換，並將該元素納入已排序區段，直到全數排序完成。3. 插入排序法 (Insertion Sort)基本原理：類似打撲克牌時整理手牌的方式。操作方式：將陣列分為已排序與未排序區段。逐一取出未排序區段的第一個元素，在已排序的序列中由後往前掃描，找到合適的位置並將其插入。4. 合併排序法 (Merge Sort)基本原理：採用「分治法」（Divide and Conquer）策略。操作方式：將陣列不斷對半切割，直到每個子陣列只剩一個元素（視為已排序）。接著將相鄰的子陣列兩兩合併，合併過程中進行大小比較，最終重組成一個完整的有序陣列。5. 堆積排序法 (Heap Sort)基本原理：利用二元樹中「最大堆積」（Max Heap）的資料結構特性來進行排序。操作方式：首先將原陣列「堆積化」建成一個最大堆積（保證父節點大於子節點）。接著將根節點（最大值）與陣列最後一個元素交換，並將已排序區段縮小。針對剩下的元素重新堆積化，重複此步驟直到排序完成。三、 在面對巨量資料時的天壤之別。在現代軟體開發中，若資料量動輒數十萬，絕不能輕易使用氣泡或選擇排序，否則將導致系統嚴重的效能瓶頸。基礎排序法仍有其價值：雖然氣泡、選擇、插入排序在大數據下表現不佳，但它們的程式邏輯簡單、易於實作，且不需要額外的記憶體空間 (In-place)。特別是插入排序，在資料量極小或是資料「幾乎已經排序好」的情況下，甚至能比高階排序法運行得更快。許多內建的排序函式庫（如 Timsort）底層都會結合插入排序來處理小區塊的資料。合併排序與堆積排序的取捨：這兩者在時間上都能穩定給出 O(n log n) 的亮眼成績。合併排序的優點是具備「穩定性」，適合用於需要維持原始相對順序的物件排序，但代價是需要消耗 O(n) 的額外空間；而堆積排序雖然是不穩定的，但它完美解決了空間複雜度的問題，只需 O(1) 的空間即可完成高效排序。總結：沒有一個絕對完美的排序演算法，只有「最適合當下情境」的演算法。了解每種排序法的原理、極限、空間耗用與穩定性，才能在實際開發中做出最佳的技術選型。

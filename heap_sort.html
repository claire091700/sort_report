堆積排序 Heap Sort

這個示範說明堆積排序的「建構最大堆積」與「提取最大值」過程及時間複雜度。

操作原理

堆積排序（Heap Sort）利用了「二元樹」的概念，但實際上是直接在陣列上操作。分為兩個主要階段：

  1. 建構最大堆積 (Build Max Heap)：將陣列調整為「最大堆積」狀態（即每個父節點的值都大於或等於其子節點），此時陣列的第一個元素一定是最大值。
  2. 排序與堆積化 (Extract & Heapify)：將目前的最大值（根節點，也就是陣列首位）與陣列未排序部分的最後一個元素交換，將其視為「已排序」。然後針對剩下的未排序元素重新進行「堆積化」，恢復最大堆積狀態。重複此動作直到全部排序完成。

時間與空間複雜度

  • 時間複雜度（最佳、最壞與平均情況）: $O(n \log n)$ - 建構最大堆積需要 $O(n)$，後續 $n-1$ 次的提取與堆積化每次需要 $O(\log n)$。
  • 空間複雜度: $O(1)$ - 雖然概念上像樹狀結構，但所有交換與推移都在原陣列內完成，屬於原地排序演算法（In-place sorting）。

演算法偽代碼 (Pseudocode)

function heapSort(A)
    n = length(A)
    
    // 階段一：建構最大堆積
    for i from floor(n/2) - 1 down to 0 do
        heapify(A, n, i)
    end for
    
    // 階段二：依序將最大值移至尾端，並縮小堆積範圍
    for i from n - 1 down to 1 do
        swap(A[0], A[i])
        heapify(A, i, 0)
    end for
end function

function heapify(A, n, i)
    largest = i
    left = 2 * i + 1
    right = 2 * i + 2
    
    if left < n and A[left] > A[largest] then
        largest = left
    end if
    
    if right < n and A[right] > A[largest] then
        largest = right
    end if
    
    if largest != i then
        swap(A[i], A[largest])
        heapify(A, n, largest)
    end if
end function

選擇排序 Selection Sort

這個示範說明選擇排序尋找最小值的步驟、交換過程與時間複雜度。

操作原理

選擇排序（Selection Sort）的概念非常直觀：將陣列分為「已排序」與「未排序」兩個區段。每一輪會在「未排序」的區段中尋找最小值，找到後，將這個最小值與未排序區段的「第一個元素」進行交換，然後將已排序區段往後推移一個位置。重複這個動作直到全陣列排序完成。

註：在此示範中，紅色柱子代表目前記錄的最小值，黃色柱子代表正在掃描比較的元素。

時間與空間複雜度

  • 時間複雜度（最壞情況）: $O(n^2)$ - 無論陣列狀態為何，都需要執行兩層迴圈尋找最小值。
  • 時間複雜度（平均情況）: $O(n^2)$。
  • 時間複雜度（最佳情況）: $O(n^2)$ - 與氣泡排序不同，選擇排序無法透過提早結束來優化最佳情況的時間。
  • 空間複雜度: $O(1)$ - 只需要常數級的額外空間來記錄索引與暫存交換變數。

演算法偽代碼 (Pseudocode)

function selectionSort(A)
    n = length(A)
    for i from 0 to n - 1 do
        // 假設未排序區段的第一個元素是最小值
        minIndex = i
        
        // 在剩下的未排序元素中尋找真正的最小值
        for j from i + 1 to n - 1 do
            if A[j] < A[minIndex] then
                minIndex = j
            end if
        end for
        
        // 如果找到的最小值不是原本預設的第一個元素，則交換
        if minIndex != i then
            swap(A[i], A[minIndex])
        end if
    end for
end function

插入排序 Insertion Sort

這個示範說明插入排序尋找適當位置的步驟、推移過程與時間複雜度。

操作原理

插入排序（Insertion Sort）就像打撲克牌時整理手牌一樣。它會將陣列分為「已排序」與「未排序」兩部分。一開始，將陣列的第一個元素視為已排序。接著，逐一取出未排序部分的元素，在已排序的部分中由後往前掃描，找到合適的位置並「插入」。

*註：為了在網頁中能清楚呈現元素的移動軌跡，此處動畫以「相鄰元素不斷交換」的方式來視覺化表現向後推移的過程。

時間與空間複雜度

  • 時間複雜度（最壞與平均情況）: $O(n^2)$ - 陣列為反序或隨機排列時，需要大量的比較與移動。
  • 時間複雜度（最佳情況）: $O(n)$ - 陣列已經排序好時，每個元素只需與前一個元素比較一次，不需移動。
  • 空間複雜度: $O(1)$ - 原地排序（In-place sorting）。

演算法偽代碼 (Pseudocode)

function insertionSort(A)
    n = length(A)
    for i from 1 to n - 1 do
        key = A[i]
        j = i - 1
        
        // 將大於 key 的元素向後移
        while j >= 0 and A[j] > key do
            A[j + 1] = A[j]
            j = j - 1
        end while
        
        // 放入適當位置
        A[j + 1] = key
    end for
end function

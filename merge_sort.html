合併排序 Merge Sort

這個示範說明合併排序的分治過程、暫存陣列覆寫機制與時間複雜度。

操作原理

合併排序（Merge Sort）是一種基於分治法（Divide and Conquer）的演算法。它的核心步驟分為兩部分：

  1. 分割 (Divide)：將陣列不斷對半切割，直到每個子陣列只剩下一個元素（此時視為已排序狀態）。
  2. 合併 (Merge)：將相鄰的兩個子陣列合併成一個有序的陣列，過程中會使用額外的暫存空間，比較左右元素的大小依序填回原陣列。

*註：在此視覺化示範中，黃色柱子代表當前正在被覆寫更新的陣列位置，灰色柱子則代表剛完成局部合併的區段。

時間與空間複雜度

  • 時間複雜度（最佳、最壞與平均情況）: $O(n \log n)$ - 無論陣列初始狀態為何，都需要穩定地進行對半切割（$\log n$ 層）與線性合併（$n$）。
  • 空間複雜度: $O(n)$ - 合併過程需要建立額外的暫存陣列來儲存子區段的元素，不屬於原地排序演算法。

演算法偽代碼 (Pseudocode)

function mergeSort(A, left, right)
    if left >= right then
        return
    end if
    
    mid = floor((left + right) / 2)
    mergeSort(A, left, mid)
    mergeSort(A, mid + 1, right)
    merge(A, left, mid, right)
end function

function merge(A, left, mid, right)
    L = A[left ... mid]     // 建立左暫存陣列
    R = A[mid + 1 ... right] // 建立右暫存陣列
    i = 0, j = 0, k = left
    
    while i < length(L) and j < length(R) do
        if L[i] <= R[j] then
            A[k] = L[i]
            i = i + 1
        else
            A[k] = R[j]
            j = j + 1
        end if
        k = k + 1
    end while
    
    // 複製剩餘未比較完的元素
    while i < length(L) do
        A[k] = L[i]
        i = i + 1; k = k + 1
    end while
    
    while j < length(R) do
        A[k] = R[j]
        j = j + 1; k = k + 1
    end while
end function

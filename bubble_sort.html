氣泡排序 Bubble Sort

這個示範說明氣泡排序的步驟、交換過程與時間複雜度。

操作原理

氣泡排序（Bubble Sort）是一種簡單的排序演算法。它會重複地走訪要排序的數列，一次比較兩個相鄰的元素。如果它們的順序錯誤，就把它們交換過來。走訪數列的工作會重複地進行，直到沒有再需要交換的元素，這意味著最大（或最小）的元素會像氣泡一樣「浮」到陣列的頂端。

時間與空間複雜度

  • 時間複雜度（最壞與平均情況）: O(n²) - 陣列為反序或隨機排列時。
  • 時間複雜度（最佳情況）: O(n) - 加入「提早結束」機制後，當資料已經是排序好的狀態，只需要做一次完整的掃描即可結束。
  • 空間複雜度: O(1) - 只需要使用常數級的額外空間來暫存交換的變數，屬於原地排序演算法（In-place sorting）。

演算法偽代碼 (Pseudocode)

function bubbleSort(A)
    n = length(A)
    for i from 0 to n - 1 do
        swapped = false // 提早結束的優化標記
        // 每一輪會把最大值推到最後面，所以內圈只要跑到 n - i - 1
        for j from 0 to n - i - 2 do
            if A[j] > A[j+1] then
                swap(A[j], A[j+1])
                swapped = true
            end if
        end for
        // 如果這一輪沒有發生任何交換，代表陣列已經排序完成
        if not swapped then
            break
        end if
    end for
end function
